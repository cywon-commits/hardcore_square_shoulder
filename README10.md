# HCSS 예비 실행 10 의뢰서: 위상 결함(4차원 버거스 벡터)과 녹음

## 1. 이론

들어올림 높이장 w(r)는 결함 없는 타일링에서 곡률 0(경로 무관)이고, 위상 정보는 홀로노미에 담긴다.

- **버거스 벡터.** 어깨 결합 그래프(가브리엘 결합)의 면을 반시계로 돌며 방향 등급 k마다 ζ^k를 더한 홀로노미 b = Σζ^k를 ζ⁴ = ζ² − 1로 줄이면 기저 {1, ζ, ζ², ζ³}의 **정수 4-벡터**가 된다(ζ = e^(iπ/6)). b_∥ = Σ b_j ζ^j, b_⊥ = Σ b_j ζ^(5j). 노름 N(b) = |b_∥|²|b_⊥|²는 정수여야 하고(자체 검증), 주기 상자에서 총합은 0이어야 한다(위상적 중성). 완전한 타일링의 면(A 삼각형, 마름모)은 모두 b = 0.
- **예측 1 (가장 흔한 전위).** 단원 계열 ζ^k(1 − ζ)^n: |b_∥| = (2 sin 15°)^n = 0.518^n, |b_⊥| = (2 sin 75°)^n = 1.932^n(변 단위). n = 1의 b_∥는 마름모의 짧은 대각선, 곧 코어 접촉 벡터(길이 σ). 탄성 에너지 ∝ K_ph|b_∥|² + K_phason|b_⊥|²에서 R = K_ph/K_phason에 대해 n = 1이 n = 0보다 싼 조건 R > 3.73, n = 2가 n = 1보다 싼 조건 R > 51.9. 단단한 접촉 계에서는 포논 강성이 커서 **n = 1, 2가 지배**해야 한다(거의 순수한 페이존 전위).
- **예측 2 (녹음 = 해리).** 녹는점 아래에서는 전위가 버거스 벡터를 상쇄하는 쌍으로 묶여 있고, 위에서는 풀린다. 지표: 가장 가까운 결함이 자기 버거스 벡터를 정확히 상쇄하는 비율(묶임 비율), 크기 R 창의 순 b_⊥ 요동 ⟨|Σb_⊥|²⟩ ∝ R^x의 지수 x(묶인 쌍 ≈ 1, 자유 ≈ 2).

**개발 환경 미리보기**(hexlat 출발, N = 931, 온도마다 1.2만 스윕 후 스냅샷 하나): 모든 노름이 정수, 총 b = 0. 결함은 거의 전부 n = 1과 n = 2(비슷한 수), n = 0은 T = 0.15에서 2개, 단원이 아닌 것(노름 4, 13)은 드묾. 묶임 비율은 T = 0.10, 0.12에서 1.00, 0.135와 0.15에서 0.40, 0.41.
