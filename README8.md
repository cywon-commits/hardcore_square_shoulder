# HCSS 예비 실행 8 의뢰서: 질서 변수로 본 상과 상전이

## 1. 질서 변수 (이론)

λ* = 2cos15°의 모든 타일링 상(A 결정, B 결정, hexlat, 3.12.12, 12회 상)은 같은 타일로 된 들어올림 공간의 곡면이고, 서로 다른 것은 평균 기울기, 곧 **페이존 변형** E = ∂w/∂r 뿐이다. 이것이 이 계의 질서 변수다.

- **두 기약 성분.** w = α z + β z̄ (z 물리, w 수직 좌표, 복소 표기)로 쓰면, 물리 공간을 φ 돌릴 때 수직 공간은 5φ 돌므로 α → e^(4iφ) α (전하 4), β → e^(6iφ) β (전하 6). 12회 대칭은 E = 0을 강제하고, β만 있으면 6회 대칭, α만 있으면 4회 대칭이다.
- **정확한 관계.** 수직 공간에서 30° 마름모의 면적은 +1/2, 정삼각형은 −√3/4이므로, 선형 변형에서 수직 면적 밀도 = det E:

      η ≡ (n_R/2 − √3 n_A/4) / (n_R/2 + √3 n_A/4) = det E = |α|² − |β|²

  (n_A: A 삼각형 수, n_R: 마름모 수 = B 삼각형 수/2). A 결정 η = −1, B 결정 +1, 12회 상 0(조성 삼각형 : 마름모 = 2/√3, x_A = 1/(1+√3) ≈ 0.366).
- **압력은 η의 짝 장.** 엔탈피가 조성에 선형이므로 공존 압력 근처에서 h = (P − P*)|∂v/∂η|, |∂v/∂η| = 0.634 σ²(λ*). 엔트로피 강성으로 ΔF/N = (k_BT/2)(K_α|α|² + K_β|β|²) − hη이고, 12회 상은 −k_BT K_β/2 < h < k_BT K_α/2에서 국소 안정. 따라서 국소 불안정 창 ΔP_sp = T (K_α + K_β)/(2 × 0.634). 실제 상전이는 멀리 있는 결정(η = ±1)으로의 1차 전이라 먼저 일어나므로 **ΔP_FL ≤ ΔP_sp**여야 한다.
- **국소 대리 변수.** 어깨 결합의 ψ₄는 α와, ψ₆는 β와 같은 전하를 가진다(대리 변수; 비례는 구조마다 다르므로 정성적으로 쓴다).

개발 환경 확인(이상 구조): η와 det E가 A, B, rows, hexlat, 3.12.12, 2차 근사 결정 모두에서 소수 다섯째 자리까지 일치(감김 맞춤 잔차 ~10⁻¹⁴). 3.12.12: |β| = 0.0718 = (2−√3)², α = 0. 2차 근사 결정: |β| = 0.0052 = (2−√3)⁴, α = 0. A: β = 1, α = 0. B: |α| = 2, |β| = √3. 열적 요동이 있는 A │ hexlat 구조에서도 η(개수) = −0.319 대 det E = −0.316.

## 2. 네 가지 분석

| | 분석 | 데이터 | 예측 |
|---|---|---|---|
| 1 | η = det E 검증 | 이상 구조 + 기존 스냅샷(runs2/, coex/) | 열적 구조에서도 분류 오차 수준 안에서 일치. 결함(짧은 고리의 수직 불일치)이 있으면 그 수와 함께 보고 |
| 2 | A → 타일링 변환 (예비 3) | coex/A_T*, coex/B_T* 스냅샷 | 생성 타일링은 삼각형이 많아 η < 0, 따라서 **전하 6형(β) 변형**: 생성 영역에서 ψ₆가 크고 ψ₄는 작음, 전역 \|β\|² − \|α\|² ≈ −η. B │ 타일링은 η 분포가 시간에 따라 변하지 않음 |
| 3 | 엔트로피 강성과 창 | 2차 근사 결정의 T → 0 타일링 MC(뒤집기 + 재채우기) | ⟨\|w_q\|²⟩ = 8/(A K_area q²)에서 K_sum. ΔP_sp ≥ ΔP_FL (T = 0.06: 0.067, T = 0.08: 0.088) |
| 4 | 녹음 경로 (예비 2) | runs2/T*_* 스냅샷 | 2차원에서 병진 질서(S_peak/N)가 먼저, 12회 방향 질서(ψ₁₂, g₁₂)는 나중에 사라질 수 있음(중간 "도데카틱" 창). η는 녹기 전까지 초기값 유지(동결) |

개발 환경의 짧은 시험(2차 근사 결정 2 × 3, 700 스윕): K_sum ≈ 4.3/입자(파수별 1.1~6.5로 흩어짐), ΔP_sp(T = 0.06) ≈ 0.21 > 0.067. 뒤집기가 모든 페이존 모드를 섞지 못하면 K를 과대평가하므로, 본 실행은 두 크기 × 두 시드로 수렴을 본다.
