# HCSS 예비 실행 4 의뢰서: 타일링 안정 창의 (λ, P, T) 예측 검증

## 1. 배경

예비 실행 3b에서 3.12.12 타일링(12각형마다 4421가지 채우기 중 독립 선택, s_conf ≥ ln4421/19 = 0.442)이 λ = 1.93, P = 0.735에서 B 결정보다 Δ(βg) = −0.10~−0.11 낮음이 두 온도·두 크기에서 5~7σ로 확정되었다. A 결정은 B보다 0.66 높다. Δ(βg)가 온도에 무관했던 것은 단단한 접촉 극한의 예측(진동 엔트로피 = 2 ln T + 구조별 기하 상수)과 맞는다.

## 2. 이론: 상수 두 개로 정해지는 안정 창

녹는점 아래에서 구조 X의 자유에너지는 βg_X = h₀,X/(k_BT) − c_X − s_conf,X + (모든 구조에 공통인 항)이고, h₀ = e₀ + P v₀는 T = 0 접촉 구조의 엔탈피, c_X는 T와 P에 무관한 기하 상수다. 따라서 B, A 기준으로

    D_tB = [ (e_t − 1) + P (v_t − v_B) ] / T − σ_B
    D_tA = [  e_t      + P (v_t − v_A) ] / T − σ_A

이고, 엔트로피 상수 σ_B, σ_A는 기준점 하나(λ = 1.93, P = 0.735, T = 0.06)의 측정으로 정해진다(예비 실행 3·3b 값으로 σ_B ≈ 0.158, σ_A ≈ 0.80). 여기서

    v_A = (√3/2) λ²,  v_B = √(λ² − 1/4),  v_t = max(λ, λ*)² (14√3 + 24)/76,  e_t = 12/19

이다. λ < λ*에서는 30° 마름모의 짧은 대각선이 1보다 짧아지므로 타일링은 변 λ*로 늘어난 채로만 존재하고(v_t가 λ*에 고정), λ > λ*에서는 변 λ로 커지되 마름모 코어 쌍이 접촉에서 떨어진다. B 결정은 꼭지각 α_B = 2 arcsin(1/2λ)인 접촉 구조다. 타일링이 안정한 압력 창은

    P_min = (e_t − T σ_A)/(v_A − v_t)  <  P  <  P_max = (1 − e_t + T σ_B)/(v_t − v_B)

이며, 다음을 예측한다.

- 창의 폭은 T에 비례한다(λ = 1.93에서 T = 0.06: 0.681~0.748, T = 0.08: 0.662~0.754).
- λ 방향으로 비대칭이다. λ < λ*에서는 창이 빨리 닫혀 λ = 1.92에서 T > 0.041, 1.91에서 T > 0.075, 1.90에서 T > 0.109(녹는점 근처) 이상이어야 열린다. λ > λ*에서는 오래 유지되고 낮은 압력 쪽으로 이동한다(λ = 1.96, T = 0.06: 0.657~0.695).

**검증 점과 예측** (T = 0.06 기본):

| λ | P | T | 예측 D_tB | 예측 D_tA | 예측 안정 상 |
|---|---|---|---|---|---|
| 1.93 | 0.66 | 0.06 | −0.741 | +0.301 | A |
| 1.93 | 0.70 | 0.06 | −0.405 | −0.270 | 타일링 |
| 1.93 | 0.735 | 0.06 | −0.110 | −0.770 | 타일링 (기준점) |
| 1.93 | 0.76 | 0.06 | +0.101 | −1.127 | B |
| 1.93 | 0.70 | 0.08 | −0.343 | −0.404 | 타일링 |
| 1.93 | 0.77 | 0.08 | +0.099 | −1.153 | B |
| 1.91 | 0.728 | 0.06 | +0.082 | +0.137 | A |
| 1.92 | 0.721 | 0.06 | −0.103 | −0.170 | 타일링 |
| 1.94 | 0.702 | 0.06 | −0.275 | −0.457 | 타일링 |
| 1.96 | 0.676 | 0.06 | −0.173 | −0.283 | 타일링 |
| 1.96 | 0.735 | 0.06 | +0.362 | −1.156 | B |

(1.90/0.735와 1.92/0.735도 계산해 λ < λ* 쪽을 촘촘히 본다.)

**예상되는 이탈 (λ < λ*).** 개발 환경의 작은 계 시험(N ≈ 300, 짧은 표본)에서 λ = 1.96은 예측과 맞았지만(측정 −0.20 대 예측 −0.17), λ = 1.91에서는 예측(+0.08)과 반대로 타일링이 이겼다(약 −0.24). 가능한 이유: λ < λ*에서 타일링은 코어 접촉 때문에 변이 λ*로 늘어나 있으므로 어깨 접촉(λ)에 약 λ* − λ의 여유가 생기고 마름모 각도도 휠 수 있어, 네트워크가 더 이상 꽉 끼이지 않는다. 그러면 c_t가 커지고(진동 엔트로피 증가) v_t도 λ*-값보다 작아질 수 있어, 위 이론의 λ < λ* 쪽 창은 **비관적(보수적) 추정**이 된다. 이번 실행이 이 이탈의 크기를 정한다.

## 3. 새로 추가된 것

| 항목 | 내용 |
|---|---|
| `lattice_state("B", λ)` | 임의 λ의 접촉 B 결정(꼭지각 α_B(λ), 짧은 대각선 1) |
| `lattice_state("dodeca"/"hexlat", λ)` | 변 max(λ, λ*)의 30° 타일링 |
| `theory_window.py` | 위 이론으로 각 점의 D_tB, D_tA 예측, Frenkel–Ladd 측정과 비교 표, (λ, P) 평면의 창 그림(측정 승자 표시, 예측과 일치하면 녹색) |
| `run_package4.sh` | 14개 점 × (A, B, dodeca) = 42개 Frenkel–Ladd |

개발 환경 확인: 테스트 16개 통과(λ = 1.91, 1.96에서 B 결정은 입자당 코어 접촉 1쌍, 3.12.12는 짧은 변 쌍 12/19).

## 5. 보고할 내용 (`results4.md`)

1. 두 기준점(T = 0.06, 0.08)에서 얻은 σ_B, σ_A와 그 차이(온도 무관성 검사).
2. 모든 점의 예측 대 측정 D_tB, D_tA(2σ 오차)와 승자 일치 여부 표(`summary4.txt`), 창 그림(`theory_window_T006.png`).
3. 압력 방향(λ = 1.93): A → 타일링 → B 순서와 경계 위치가 예측과 맞는지, T = 0.08에서 창이 넓어지는지.
4. λ 방향: λ > λ* 점들이 맞는지, λ < λ* 점들에서 이탈의 크기와 부호(2절의 "예상되는 이탈").
5. 각 구조의 입자당 v − v₀ (λ < λ*의 타일링에서 늘어난 여유가 부피에 보이는지).
