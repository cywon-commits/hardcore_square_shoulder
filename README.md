# HCSS λ* = 2cos15° 예비 실행 의뢰서

## 1. 목적

본 스캔(약 300~3000 코어-시간) 전에, 삼중점 근처 한 상태점에서 **타일 조성 x_A의 적분 자기상관 시간 τ_int**를 측정해 계산 계획을 확정한다. 함께 확인할 것은 (1) 코드 처리량, (2) 서로 다른 초기 상태가 같은 상태로 수렴하는지, (3) 국소 이동만으로 이완이 충분한지(타일 뒤집기 이동이 필요한지)이다.

## 2. 배경과 이론적 예측

2차원 강체 코어(σ = 1) + 계단 어깨(높이 ε, 범위 λ) 모형에서, 이론은 λ* = 2cos15° ≈ 1.9319, P* = (√3 − 1)ε/σ² ≈ 0.7321에서 A(한 변 λ 정삼각형), B(30° 이등변, 밑변 1), C(150° 이등변) 세 타일이 동시에 축퇴하고, 엔트로피로 안정화된 **12회 대칭 무작위 타일링**이 나타난다고 예측한다.

| 예측 | 값 (T → 0) |
|---|---|
| 조성 | x_A = 1/3, x_B = 2/3 (삼각형 : 얇은 마름모 = 1 : 1) |
| 입자당 에너지 | e/ε = 2/3 |
| 밀도 | ρ₁₂ = 42 − 24√3 ≈ 0.431 |
| 코어 접촉 | 입자당 2/3쌍, 평균 코어 이웃 수 4/3 (사슬·망) |
| 경쟁 결정 | A: ρ ≈ 0.31, B: ρ ≈ 0.536, A+C 혼합: ρ ≈ 0.845 |

유한 온도에서는 진동 때문에 밀도가 예측보다 약간 낮다(작은 계 예비 확인: T* = 0.15에서 ρ ≈ 0.40~0.41, e/N ≈ 0.67).

전체 설계안: https://claude.ai/code/artifact/4e14265f-8ac1-4eb3-a265-05f3a79079c4

## 6. 판정 규칙

| 결과 | 결론 |
|---|---|
| τ_int(x_A) < 10⁵ 스윕, 세 초기 상태 수렴 | 낙관 계획(약 300 코어-시간)으로 본 스캔 진행 |
| 10⁵ ≤ τ_int < 10⁶ | 중간 계획; 뒤집기 이동 구현을 병행 |
| τ_int ≥ 10⁶ 또는 초기 상태별로 다른 상태에 머묾 | 본 스캔 전에 7절의 타일 뒤집기 이동 구현 |

## 7. 선택 과제: 30° 육각형 뒤집기 이동 명세

판정 결과 필요할 때만 구현한다.

- **대상**: 결합망(L 결합 = |r − λ| 작은 쌍, S 결합 = 코어 접촉)에서, 변 벡터 u, v, w (각 길이 ≈ λ, 방향 d, d+30°, d+60°)로 이루어진 육각형 영역이 삼각형 2개 + 얇은 마름모 2개로 채워진 곳. 내부 꼭짓점이 하나 있다.
- **이동**: 내부 꼭짓점을 다른 채우기의 위치로 옮긴다. 육각형 꼭짓점을 O, O+u, O+u+v, O+u+v+w, O+v+w, O+w라 하면 내부 꼭짓점은 O+v 또는 O+u+w이고, 이동 벡터는 ±(u + w − v)이다.
- **상세 균형**: 현재 상태의 후보 육각형 수 n_old 중 하나를 균등하게 고르고, 새 상태의 후보 수 n_new를 세어 min(1, (n_old/n_new)·exp(−βΔU))로 수락한다. 이동 후 겹침(r < 1)은 즉시 기각한다.
- **검증**: 뒤집기 이동만 켜고 β → 0에서 후보 육각형의 두 상태 점유가 1:1인지, 그리고 증분 에너지 일관성을 테스트에 추가한다.

## 8. 알려진 한계

- 이동은 국소 입자 이동과 상자 이동뿐이다. 스텝 크기는 튜닝 구간에서만 조정한다.
- 상자 이동은 스윕당 1회이며 매번 전체 재계수(O(N))를 한다.
- 최소 영상 규약은 상자의 두 수직 폭이 3λ보다 클 때만 쓰며, 이를 만족하지 않는 상자 이동은 기각한다(|b| ≤ a/2로 전단 축약).
- 구조 분석의 허용 오차(tol_in = 0.06, tol_out = 0.15, tol_core = 0.06)는 g(r) 봉우리 폭에 맞춰 조정할 수 있다. 조정했다면 보고에 명시한다.
