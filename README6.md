# HCSS 예비 실행 6 의뢰서: 잼 바닥, 동역학적 갇힘, 그리고 타일링 띠의 진짜 아래쪽 끝

## 1. 배경 (예비 실행 5)

- λ < λ* 이탈의 1/T 스케일링이 확인되어(κ_eff ≈ 1.6, T = 0.06과 0.08에서 같음), 이탈이 단단한 접촉 계의 여유 효과임이 확정되었다.
- λ = 1.85에서 A → 타일링 → B 순서가 나왔지만 타일링 우위는 약했고(P ≈ 0.82), λ = 1.80의 타일링 Frenkel–Ladd는 실패했다(기준 자리 = 이상 격자 → 휜 실제 구조와 어긋나 아인슈타인 기준 상태가 전부 겹침).
- **수수께끼**: 측정된 타일링 부피 부족분은 모든 점에서 0.9(λ* − λ)이고 T, P에 무관한데, T = 0 잼 계산(접촉 그래프 고정, 코어 ≥ 1, 나머지 ≥ λ에서 면적 최소화)은 1.48(λ* − λ)이다. 개발 환경에서 섞인 채우기의 큰 단위 칸(기울기 1.47)과 전단 고정(1.44~1.46)을 계산해 두 가설을 배제했다.

## 2. 남은 두 가설

1. **동역학적 갇힘**: 이상 구조에서 잼 구조로 가려면 마름모들이 협동해 크게 회전해야 하고, 그 경로에 어깨 겹침(장벽 ≈ e^(−ε/k_BT) ≈ e^(−17))이 필요하다면 시뮬레이션은 덜 압축된 준안정 바닥에 갇힌다. 그러면 진짜 평형 타일링은 더 압축되어 **더 안정**하다.
2. **엔트로피적 선호**: 완전히 압축된 등정역학 상태는 자유 부피가 작아서, 유한 온도에서는 덜 압축된 상태가 유리하다. 그러면 지금까지의 측정이 평형이다.

**개발 환경 시험 (N ≈ 300, 짧은 실행, T = 0.06, λ = 1.80, P = 0.895).** 잼 구조에서 시작한 NPT는 v_jam + 2T/P에 머물렀고(v − v_jam = 0.131 대 2T/P = 0.134), 같은 채우기의 잼 바닥이 이상 구조 바닥보다 βg가 입자당 약 **0.74 낮았다**. 가설 1을 지지한다. 평균 위치 기준 자리는 B 결정에서 이상 자리 방식과 1σ 안에서 일치했다(45.211 ± 0.021 대 45.182 ± 0.019).

## 5. 보고할 내용 (`results6.md`)

1. 검증: λ = 1.93에서 평균 위치 방식과 예비 실행 3b(이상 자리)의 βg 차이(B, dodeca).
2. 잼 시작 대 이상 시작 NPT(λ = 1.90, 1.85, 1.80): 초반·후반 평균 부피, 부족분/(λ* − λ)이 1.48 근처에 머무는지(가설 1) 0.9로 돌아가는지(가설 2), 이상 시작은 시간이 지나며 더 압축되는지.
3. 자유에너지: 각 점의 A, B, 타일링 세 가지(dodeca 무작위·이상, dodeca1 이상, dodeca1_jam)의 βg, D_tB, D_tA(2σ), 승자. 같은 채우기의 잼 바닥 − 이상 바닥 차이.
4. λ = 1.85, 1.80의 압력 주사에서 잼 타일링의 안정 창(있다면 범위).
5. 겹침 없는 비율, 사용된 Λ_max, 기준 자리 종류(평균/대체), rms 차이.
