# HCSS λ* = 2cos15° 예비 실행 3 의뢰서: 타일링은 열역학적으로 안정한가

## 1. 배경

예비 실행 2(results2.md)에서 rows·hexlat 타일링은 T* = 0.12까지 e/N = 2/3을 유지하고 0.12~0.15에서 녹았다. A, B 결정, 타일링은 서로에게 전혀 수렴하지 않았고(동역학 동결), 유체를 서냉해도 타일링이 생기지 않았다. 따라서 상대 안정성은 수렴으로는 판정할 수 없고, (1) 계면을 둔 직접 공존과 (2) 자유에너지 계산으로 판정한다.

## 2. 이론적 틀과 예측

**열팽창 법칙.** 낮은 온도에서 접촉이 단단한 벽처럼 작동하면 βP(V − V₀) = dN이므로 v(T) ≈ v₀ + 2T/P이며, 이것은 구조와 무관하다. 예비 실행 2의 측정값이 A, B, 타일링 모두에서 이 식과 일치했다(예: T = 0.04에서 v − v₀ = 0.105 / 0.095 / 0.108, 2T/P = 0.109).

**자유에너지 차이.** 압력 항의 열적 부분이 상쇄되므로 입자당

    Δg(T) ≈ Δh₀ − T (Δs_vib + Δs_conf)

이다. λ = 1.93, P = 0.735에서 h₀ = e₀ + P v₀는 B가 가장 낮고 A는 +0.0009ε, 타일링은 +0.0003ε이다(타일링의 h₀는 A와 B의 1:2 내분).

**배치 엔트로피의 엄밀한 하한.** hexlat 앙상블에서 각 육각형 내부 입자는 독립적으로 두 위치 중 하나를 가질 수 있으므로 s_conf ≥ ln2/3 ≈ 0.231 k_B (입자당). 진짜 무작위 타일링(12회 대칭점)의 엔트로피는 이보다 크다.

**가설.** 진동 엔트로피 차이 Δs_vib(결정 − 타일링)가 0.23 k_B보다 작으면 타일링이 녹는점 아래에서 안정한 상이고, 예비 실행 2에서 A·B가 남아 있었던 것은 준안정 동결이다. 세포 모형의 거친 추정은 |Δs_vib| ≲ 0.05로 가설을 지지한다.

**주의 (개발 환경 시험값).** N ≈ 240, 짧은 표본의 시험 실행에서는 βg가 B < 타일링(+0.066 ± 0.025) < A(+0.65)로 나왔다. 계가 작고 표본이 짧아 결론으로 쓸 수 없지만, 경쟁 상대는 A가 아니라 B이고 B와 타일링의 차이가 k_BT의 수 % 수준으로 작을 수 있다는 신호다. 본 실행이 이를 판정한다.

## 3. 새로 추가된 것

| 파일 | 내용 |
|---|---|
| `fl_free_energy.py` | 고정 구조의 Gibbs 자유에너지. NPT로 평균 상자를 구하고(초기 격자를 v₀ + 2T/P로 미리 팽창), 입자 0을 고정한 아인슈타인 분자 Frenkel–Ladd 적분(Gauss–Legendre, ln Λ 변수), Λ_max는 겹침 없는 비율 ≥ 0.8이 되도록 자동 조정. hexlat은 −ln2/3을 더한 타일링 값도 보고 |
| `run_coex.py` | 결정 slab(B 또는 A) │ hexlat slab, 두 계면. 두 상이 같은 y 주기를 갖도록 B·A는 길이 L 격자 벡터, hexlat은 T₁ − T₂ = u − w(길이 L)를 y축에 맞춤(변형 없음). 상자는 a, c만 움직임(전단 없음). x 구간별 타일 조성으로 각 구간을 타일링 / B / A / 기타로 분류해 시간에 따라 기록 |
| `summarize3.py` | 공존: 구간 수의 처음·끝·추세와 x_A 시공간 그림. 자유에너지: 구조별 βg 표, 최저값 대비 차이, 두 온도 사이 Gibbs–Duhem 검사 (βg)₂ − (βg)₁ ≈ h̄(β₂ − β₁) |
| `hcss_analysis.tol_out_auto` | 온도 맞춤 허용 오차 tol_out = 0.10 + 2T/(Pλ) (공존 분석에 사용) |
| `test_fl.py` | 조화 극한(Λ⟨Σ\|Δr\|²⟩ = N − 1), 입자 0 고정·에너지 장부, ΔA₁ 기준값, slab 상태의 조성 |

개발 환경 확인: 전체 테스트 13개 통과. 자유에너지 시험에서 부피 팽창이 2T/P와 일치(0.168 / 0.157 / 0.167 대 0.163), ΔA₁/N이 기준 에너지 βe₀(A 0, B 1/T, 타일링 (2/3)/T)와 일치. 공존 시험(N ≈ 600, 3000 스윕)에서 에너지 일관성 유지, 약 950 스윕/s.

## 6. 판정 규칙

| 결과 | 결론 |
|---|---|
| 공존에서 타일링 구간이 늘고, Δ(βg)(타일링 − B) < 0 (2σ 이상) | 타일링이 안정 상. 가설 지지. 다음은 12회 대칭 이동(12각형 재배열)과 λ·P 스캔 |
| 공존에서 B가 자라고, Δ(βg)(타일링 − B) > 0 (2σ 이상) | B 결정이 안정. hexlat 하한 엔트로피로는 부족; 12회 대칭 무작위 타일링의 엔트로피(> ln2/3)가 그 차이를 메울 수 있는지 이론 쪽에서 추정 필요 |
| 공존 계면이 움직이지 않고 \|Δ(βg)\| < 2σ | 판정 불가. 표본 늘리기와 N 확대 |
| 공존과 자유에너지가 서로 반대 | 공존 계면의 변형 또는 자유에너지의 유한 크기 문제를 의심; 두 결과의 조건(T, N)을 맞춰 재실행 |

## 7. 해석 시 주의

- βg의 절대값에는 열적 파장 등 상수가 들어 있으므로 같은 T, P, N에서의 차이만 의미가 있다.
- hexlat 값은 특정 뒤집기 배치 하나의 진동 자유에너지에 ln2/3을 뺀 것이다. 배치마다 진동 자유에너지가 조금씩 다를 수 있어 seed 두 개로 그 크기를 본다.
- 공존 slab은 y 방향으로는 변형이 없지만 x 방향 두께는 열팽창 차이로 조금 어긋날 수 있다. 초기 수천 스윕의 계면 재배열은 추세 계산에서 빼고 본다.
- A 결정 | 타일링 공존에서 A가 녹거나 무질서해지면 그 자체를 기록한다(A의 녹는점이 0.12~0.15 사이로 보고되었음).
