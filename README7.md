# HCSS 예비 실행 7 의뢰서: 수정된 방법으로 최종 수치와 타일링 띠의 아래쪽 끝

## 1. 배경 (예비 실행 6)

- λ < λ*에서 평형 타일링은 T = 0 잼 구조(접촉 그래프 고정, 등정역학, v_jam = v_t(λ*) − 1.48(λ* − λ)) 위에 열팽창(≈ 0.9 × 2T/P)이 얹힌 상태다. 잼 시작과 이상 시작 NPT가 같은 부피로 수렴했다.
- 예비 실행 4~5의 λ < λ* 타일링 값은 Frenkel–Ladd의 NPT가 **미리 팽창시킨** 이상 격자에서 출발해, 압축 방향의 느린 이완(이력) 때문에 덜 압축된 준안정 부피에 머문 비평형 값이었다(타일링에 불리, λ = 1.90에서 0.02, 1.85에서 0.16).
- 잼 시작 값으로 보면 타일링 창은 λ = 1.85에서 확실하고(P ≈ 0.818), λ = 1.80에서 거의 닫힌다(P ≈ 0.895에서 A와 동률).
- 잼 구조 자체는 λ = 1.70까지 존재하고 같은 기울기로 압축된다(개발 환경 확인). 따라서 띠의 끝은 접촉 그래프의 기하가 아니라 A·B 결정과의 자유에너지 경쟁이 정한다.

## 2. 이번 실행의 방법 수정

| 구조 | NPT 시작 부피 | 이유 |
|---|---|---|
| A, B 결정 | v₀ + 2T/P (이전과 같음) | 결정에는 압축 방향 이력이 없음. v₀에서 시작하면 오히려 팽창이 짧은 NPT 안에 끝나지 않음 |
| 타일링 (λ ≥ λ*: 무작위 3.12.12, λ < λ*: 잼 구조 `dodeca1_jam`) | v₀ + 0.8 × 2T/P | 평형(≈ v₀ + 0.9 × 2T/P)보다 약간 덜 팽창한 쪽에서 출발해 빠른 팽창 방향으로만 이완 |

모든 계산은 평균 위치 기준 자리(`--sites mean`), NPT 5만 스윕이며, NPT 후반의 부피 표류를 JSON에 기록한다. 개발 환경 시험(N ≈ 300): 표류 ≤ 0.002, 타일링의 v − v₀ = (0.84~0.88) × 2T/P로 예비 실행 6의 평형값과 일치.

## 3. 계산 점

| 목적 | 점 (λ, P, T) |
|---|---|
| 기준 (σ_B, σ_A) | (1.93, 0.735, 0.06), (1.93, 0.735, 0.08) |
| 예비 4~5의 λ < λ* 점 재계산 | T = 0.06: (1.90, 0.735), (1.91, 0.728), (1.92, 0.721), (1.92, 0.735); T = 0.08: (1.90, 0.735), (1.92, 0.721) |
| 띠의 아래쪽 끝 (T = 0.06) | λ = 1.85, 1.80, 1.78, 1.75 각각 P_AB(λ)와 ±0.035 |
| 끝의 온도 의존성 | T = 0.08: (1.80, 0.881), (1.78, 0.916) |

P_AB(λ, T) = (1 − 0.645 T)/(v_A − v_B)는 A와 B가 비기는 압력으로, 타일링에게 가장 유리한 압력이다(λ = 1.80에서 0.893으로 예비 실행 6의 창 중심 0.895와 일치). 점마다 A, B, 타일링 3개, 총 66개 Frenkel–Ladd.

## 5. 보고할 내용 (`results7.md`)

1. 전체 표(`summary7.txt`): 각 점의 D_tB, D_tA(2σ), 승자, NPT 부피 표류, 겹침 없는 비율.
2. λ와 T별 타일링 창(타일링이 2σ 넘게 이기는 압력), 띠의 아래쪽 끝 추정(T = 0.06, 0.08).
3. 재계산한 예비 4~5 점들의 이전 값 대비 변화와, 가중 맞춤으로 얻은 κ_eff(±오차).
4. 최종 상도 그림 `phase_window_final.png`(κ = 1.7 이론 위에 측정 승자 표시).
5. 표류가 0.005를 넘거나 겹침 없는 비율이 0.8 미만인 점은 따로 표시하고, 필요하면 NPT를 늘려 재실행.
