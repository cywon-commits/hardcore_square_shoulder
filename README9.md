## 1. 예비 실행 8에서 드러난 문제와 원인 (개발 환경에서 확인)

| 증상 (예비 8) | 원인 | 수정 |
|---|---|---|
| 균등 타일링 MC의 ⟨η⟩ = −0.074 | (a) 들로네 삼각분할의 퇴화(변이 아닌 쌍이 정확히 거리 λ)로 타일 오분류, (b) 타일링 MC의 뒤집기를 β = 10⁻⁹로 수락해 "육각형처럼 보이지만 타일링이 아닌" 배치까지 뒤집혀 타일링이 조금씩 망가짐 | (a) η를 **비용 쌍 개수 n_R과 오일러 관계(삼각형 2N개)**로: n_A = 2N − 2n_R. (b) 뒤집기 β = 10³: 올바른 뒤집기는 ΔU = 0이라 영향 없고, 잘못된 뒤집기만 막힘. 이제 η가 실행 내내 정확히 보존됨 |
| ψ₁₂ ≡ 1 | 30° 등급으로 양자화한 각도로 ψ₁₂를 계산 | 실제 결합 각도로 계산 |
| 열적 B, hexlat에서 결함 수백~수천, η ≠ det E | 온도에 맞춘 어깨 창(λ + 0.156)이 **코어 두 칸 일직선 쌍(거리 2.0, 방향이 30° 격자에서 정확히 15° 벗어남)**을 어깨 결합으로 잘못 포함 | **가브리엘 조건**: 결합을 지름으로 하는 원 안에 다른 입자가 없을 때만 접촉 결합(A, B 타일 변은 맞은편 각 60°, 75°라 항상 통과). 각 결합은 한 번만, 전역 기준 + 국소 편차로 양자화 |
| 강성 K가 크기에 따라 증가 | 장파장 모드의 \|w_q\|² 대부분이 초기 구조에 박힌 **정적 무늬**(정적 비율 0.2~0.9)였고 요동 부분은 작음. 국소 뒤집기로 장파장 페이존 모드가 거의 움직이지 않음 | 모드별로 정적 부분 \|⟨w_q⟩\|²과 요동 부분(분산)을 분리, K는 분산으로; 정적 비율 < 1/3이고 자기상관이 짧은 모드만 "평형"으로 사용 |

개발 환경 확인: 이상 구조와 **열적 구조(A, B, hexlat, 3.12.12; T = 0.04, 0.08, 전단 이동 포함 NPT)** 모두에서 η = det E가 정확히 일치하고 결함 0(들로네 "기타" 비율이 19%까지 늘어나는 T = 0.08에서도). 타일링 MC 2400 스윕에서 η가 −0.000027로 고정. 짧은 실행의 요동 강성은 q = 0.24에서 K ≈ 6, q = 0.09에서 ≈ 33으로 q에 강하게 의존(장파장 미수렴).

## 2. 이번 실행

1. **페이존 강성**: 2차 근사 결정 2 × 3(N = 1590, 시드 2개)과 3 × 4(N = 3180)에서 6만 스윕. 모드별 정적 비율이 시간에 따라 줄어드는지, 평형에 이른 모드들에서 K(q)가 평탄해지는 구간이 있는지(탄성 영역) 본다.
2. **재분석**: 고친 모듈로 예비 2(runs2/), 예비 3(coex/)의 η = det E 검증과 A → 타일링 변환.
3. **녹음 세밀 스캔**: T = 0.120~0.150을 0.005 간격, hexlat과 3.12.12 두 출발, N = 931, 12만 스윕. 실제 각도의 ψ₁₂, g₁₂(10), ψ₆, g₆(10), S_peak/N, 접촉 비율.

## 4. 보고할 내용 (`results9.md`)

1. 강성: 실행별 η 범위(보존 확인), 평형 모드 수, 모드별 K와 정적 비율 표(q 순), 시간에 따른 정적 비율 감소 여부, K(q)의 평탄 구간 값과 그로부터의 ΔP_sp 대 ΔP_FL(0.067, 0.088).
2. 재분석: 열적 스냅샷의 η, det E, 결함 수(예비 8 표와 나란히), A → 타일링의 |α|, |β|, −η 비교.
3. 녹음: 온도별(0.005 간격) 표와 그림. 방향 질서(ψ₁₂, g₁₂)와 병진 질서(S_peak/N)가 같은 온도에서 사라지는지, 사이에 방향 질서만 남는 구간이 있는지. 두 출발의 결과 차이(이력).
